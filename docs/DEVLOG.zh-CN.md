## 1. 这是什么

一个仿照 Geek Uninstaller 的 Windows 桌面工具：（a）列出所有已安装的程序，卸载时连同注册表项和残留文件一起清除；（b）查找垃圾文件并给出清理建议；（c）分析磁盘空间被什么占用。单个 x64 WinForms 可执行文件，用 Windows 自带的 C# 5 编译器构建。界面为简体中文，深色主题，控件全部自绘。

## 2. 目前实现的功能

### 应用程序页
- 数据来源：卸载注册表项（HKLM 64 位、HKLM `WOW6432Node`、HKCU）；未登记的程序文件夹（每个固定磁盘上的 Program Files、`%LocalAppData%\Programs`、盘符根目录、`Games`、`SteamLibrary\steamapps\common` 等）；通过 `Get-AppxPackage` 获取的商店应用。
- 顶层没有 exe 的厂商文件夹（如 `Tencent`、`EA`）会拆成其中的各个子程序。
- 列：名称（带图标；没有图标的用彩色首字母方块）、版本、发布者、大小、上次使用、类型、建议。点表头排序。
- 搜索框；筛选标签：全部 / 桌面程序 / 便携未注册 / 商店应用 / 建议卸载。
- 支持多选（Ctrl/Shift），批量卸载或强制删除。
- 卸载流程：运行程序自带的卸载程序（MSI 用 `msiexec /x`）→ 等用户确认卸载结束 → 扫描残留 → 列出清单 → 删除用户保留勾选的项目。
- 强制删除：跳过卸载程序，直接扫描并删除。
- 商店应用用 `Remove-AppxPackage` 卸载。
- 其他操作：修改/修复、打开安装位置、在注册表编辑器中定位、仅移除列表条目、网上搜索、通过 `winget` 更新。

### 残留扫描（`LeftoverScanner`）
- 搜索词：清理过的显示名（去掉版本号和位数）、安装文件夹名、卸载项键名；发布者单独处理。有一份黑名单排除通用词（"Microsoft"、"Update"、"Python" 等）。
- 注册表：并行完整遍历 `HKCU\Software` 和 `HKLM\SOFTWARE`。键名等于某个搜索词（深度 ≤ 4）即匹配该键；值的名称或数据引用了安装目录即匹配该值。命中 `…\shell\<动作>\command` 时删除整个动作键。发布者键只有在其下所有子键都属于该程序时才删除。
- 另外扫描：`ImagePath` 位于安装目录内的系统服务、防火墙规则、计划任务（`System32\Tasks` 下的 XML）、Roaming / Local / LocalLow / ProgramData / Program Files / Common Files / VirtualStore 下以程序命名的文件夹、开始菜单文件夹、指向安装目录的 `.lnk` 快捷方式。
- 删除（顽固文件处理，见 `src/Force.cs`）：程序启动时激活 `SeTakeOwnership`/`SeRestore`/`SeBackup`/`SeDebug` 特权。多轮结束安装目录下的进程，压制互相拉起的看门狗（如 AlibabaProtect）。对服务先禁用、停止，停不下来就按 PID 结束其进程，再 `sc delete`。遇到“访问被拒绝”时，把文件/文件夹的所有者改为 Administrators，并用完全控制替换其 DACL（清掉显式“拒绝”ACE），然后重试删除。删不掉的注册表项同样夺取所有权后重试。仍被运行中进程占用的，安排在重启后删除（`MoveFileEx`）。注册表项删除前先导出到 `Backups\<时间戳>_<名称>.reg`；值删除后变空的父键一并清理。

### 垃圾清理页
- 定向分类（系统盘）：用户临时文件、Windows 临时文件、Windows 更新下载缓存、传递优化缓存、错误报告与崩溃转储、缩略图/图标缓存、浏览器缓存（Chrome、Edge、Brave、360、QQ、Firefox）、Windows 日志、开发工具缓存（pip/npm/NuGet）、下载文件夹里的旧安装包、旧的 Windows 安装、回收站。
- 全盘遍历（并行）查找：临时文件、崩溃转储、未完成的下载、旧日志、`.bak`/`.old`、1 GB 以上的文件。跳过 Windows、Program Files、`$Recycle.Bin`、`.git`、`WinSxS`、`Package Cache` 和重解析点。
- 评分（`JunkItem.Rate`）：重要程度/安全性 50 分 + 闲置时间 30 分 + 占用大小 20 分。分级：*优先清理*（≥ 78）、*建议清理*（≥ 60）、*可以清理*（≥ 40）、*自行判断*。封顶规则：风险 3 的项目（大文件）永远是*自行判断*；风险 2 的项目（备份、旧安装包、Windows.old）最高到*可以清理*。
- 有一个虚拟的"综合清理建议"分类，把所有项目按评分排序列出。
- 可按级别一键勾选；每个分类有总开关；明细行可多选，用空格或右键菜单批量勾选。
- 清理是永久删除；被占用的文件会跳过并留在列表里。清理更新缓存时会先停止、再启动 Windows 更新服务。

### 空间分析页
- 对单个磁盘做只读的并行遍历。
- 环形饼图按文件类别显示占比（视频、图片、音频、文档、压缩包、安装包与镜像、程序与库、游戏与资源数据、开发与代码、虚拟磁盘、Windows 系统文件、其他、未能读取/系统保留），带图例。
- 概况卡片：已用/总容量、可用、文件数、文件夹数。
- 按最后修改时间分五段的文件新旧分布。
- 右侧列表三种模式：文件夹占用（前两级）、最大的文件（≥ 100 MB，前 300 个）、扩展名排行。
- 标题下方有一行结论摘要。

### 外壳
- 深色主题、侧边栏导航（带各磁盘剩余空间条）、忙碌时的流动进度线、长操作可取消。
- 程序图标由矢量代码生成（`Logo.Draw`）：一个渐变的 "G" 环，开口处碎裂成飞散的像素方块。
- 清单：`requireAdministrator`、支持高分屏、支持长路径。

## 3. 架构

文件清单见 [AGENTS.md](../AGENTS.md)。要点：

- 所有扫描器通过 `Task.Run` 在后台线程运行，用 `Action<string>` 汇报进度，响应 `CancellationToken`。并行部分会把 `AggregateException` 转回 `OperationCanceledException`。
- 忙碌时界面不禁用容器（那样会让标签变灰），而是用 `MainForm.isBusy` 拦住所有操作，并逐个禁用操作按钮。
- `DarkList` 是一个自绘的 `ListView`，所有列表都用它（大列表用虚拟模式）。它在 `WM_NCCALCSIZE` 里去掉 `WS_HSCROLL`，并让某一列自动撑满；还会重绘最后一行以下的区域，盖住系统主题画的列分隔线。
- 勾选状态保存在数据对象里（`JunkItem.Checked`、`LeftoverItem.Checked`），不在列表控件里。

## 5. 已知局限

- "上次使用"来自 UserAssist，它只记录通过资源管理器 / 开始菜单 / 桌面的启动。"无记录"不代表没用过；这类程序不给建议。
- Steam 游戏经常显示的是 Steam 自己的上次启动时间，因为它们被识别到的位置落在 Steam 文件夹里。
- 垃圾项的闲置时间取最后修改和最后访问中较新的一个；杀毒软件扫描会刷新访问时间，所以闲置时间可能偏短（偏保守的方向）。
- 便携程序的识别是启发式的，会把驱动和更新组件也列出来（如 `Google \ Update`）。删除始终需要确认。
- 有些安装位置是根据图标或卸载程序路径推断的，界面上会标注"推断"。
- 个别在开始菜单里没有条目的商店应用，名称显示为内部编号。
- 确认和结果弹窗是系统自带的浅色 `MessageBox`。
- 文件删除无法撤销。受保护的注册表键（归 TrustedInstaller 所有）会删除失败并在结果中报告。
- 名称非常通用的程序，按名称匹配可能误报；确认清单是最后一道防线。

## 6. 后续可以做的方向

不是承诺，按需挑选。

- 给纯逻辑加自动化测试：`CleanName`、`ContainsPath`、`IsSafePath`、`JunkItem.Rate`、`Usage` 解码。
- 演练模式：把将要删除的内容写成报告文件，不实际删除。
- 残留文件先移到隔离区并提供恢复，而不是直接删除。
- 用深色确认对话框替换 `MessageBox`。
- 更准确的使用数据：Prefetch 文件、BAM/DAM 注册表项、Steam 各游戏的 `appmanifest`。
- 商店应用的正式名称和图标（读取 `AppxManifest.xml` 并解析 `ms-resource:` 字符串）。
- 重复文件查找、空文件夹查找。
- 点击饼图扇区筛选列表；文件夹逐级下钻。
- 开机启动项管理、浏览器扩展管理。
- 英文界面 / 多语言。
- 把程序列表或分析结果导出为 CSV。
