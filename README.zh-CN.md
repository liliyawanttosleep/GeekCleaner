# GeekCleaner

[English](README.md) | **简体中文**

一个类似 Geek Uninstaller 的 Windows 卸载与清理工具：列出电脑上所有已安装的程序，卸载时连同注册表项和残留文件一起清除，查找垃圾文件并按清理优先级排序，还能分析磁盘空间被什么占用。

单个 `.exe`，无需安装，除了 Windows 10/11 自带的 .NET Framework 4.x 之外没有任何依赖。界面为简体中文。

## 功能

- **应用程序** —— 从注册表（64 位、32 位、当前用户）、各磁盘上未登记的便携程序文件夹、微软商店应用三个来源列出程序。支持搜索、按类型筛选、按任意列排序。
- **卸载并清理残留** —— 先运行程序自带的卸载程序，再扫描注册表（`HKCU\Software`、`HKLM\SOFTWARE`，含 `WOW6432Node` 和 `Classes`）、系统服务、防火墙规则、计划任务、用户数据文件夹和快捷方式。找到的内容全部列出，由你确认后才删除。注册表项删除前会先备份成 `.reg` 文件。
- **强制删除** —— 不运行卸载程序，直接做同样的扫描，适合卸载程序损坏或便携程序。
- **批量处理** —— 用 Ctrl/Shift 选中多个程序，一次处理完。
- **基于使用频率的建议** —— 读取 Windows 的启动记录，显示每个程序上次使用的时间，标出长期没启动过又占用很大的程序。
- **垃圾清理** —— 扫描所选磁盘上的临时文件、缓存、崩溃转储、系统更新残留、回收站等。每一项按重要程度、闲置时间、占用大小打分，分为四个优先级，可按级别一键勾选。
- **空间分析** —— 环形饼图显示各类文件占比，另有文件夹占用（前两级）、文件新旧分布、最大的文件、扩展名排行。只读。
- **更新** —— 调用 `winget` 更新单个程序或列出所有可更新项。

## 编译

只需要带 .NET Framework 4.x 的 Windows（系统自带）。不需要 SDK，也不需要 NuGet。

```bat
build.bat
```

它会用矢量绘图代码重新生成 `src\app.ico`，再用 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译出 `GeekCleaner.exe`。

程序启动时会请求管理员权限（读取和删除系统级内容需要）。

## 安全提示

本工具会永久删除文件和注册表项。删除的文件不经过回收站。注册表删除会备份到 `Backups\` 文件夹；文件删除没有备份。确认之前请逐项检查清单。
